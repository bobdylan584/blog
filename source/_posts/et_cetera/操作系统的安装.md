# 操作系统的安装

## 组装新电脑

一台电脑=主板+CPU+内存条+硬盘等主要部件。

假设电脑是一台车，主板就是一个车架子和电路板，负责协调所有硬件工作。而BIOS集成在主板上，是主板自带的程序。其作用是整台车的打火器，让主板工作，是电脑接上电源启动后，最先启动的组件。

## 主板烧录操作系统

### 主板

主板图片：

![主板](https://bob-blog-image.oss-cn-shanghai.aliyuncs.com/et_cetera/mainboard.png)

定义：主板是一块物理电路板，它是计算机所有核心硬件的连接中心和通信枢纽。它是硬件平台，让CPU、内存、硬盘、显卡等能连接在一起协同一起工作。

包含：

物理接口（CPU插槽、内存条插槽、USB插口、显卡插槽、电源插口、硬盘接口、电池包接口）

固件芯片（flash ROM）这块芯片存储着BIOS或者UEFI固件

......

#### BIOS程序

1、定义：BIOS(老式主板) 的全称是：Basic Input/Output System 基本输入输出系统。BIOS是一种固化在计算机主板上的固件（firmware），是计算机启动时最先运行的软件之一。

2、主要作用：

开机自检：检查内存、CPU、硬盘等硬件是否正常

硬件初始化：启动并配置基本的硬件设备

引导操作系统：找到硬盘、U盘等设备上的操作系统，并将其加载到内存中，交给操作系统继续启动

提供底层接口：为操作系统和硬件之间提供最基本的通信支持

#### UEFI程序

UEFI 的全称是：Unified Extensible Firmware Interface；统一可扩展固件接口

定义：UEFI是一种现代的、用来替代传统BIOS的固件接口标准，它在计算机启动过程中起到核心的作用，是操作系统和硬件之间的桥梁

UEFI的主要功能和传统BIOS差不多一致，现在的（2010年以后）主流机型都使用UEFI，而不是BIOS，它是新一代更强大的BIOS

## BIOS和UEFI的区别

### UEFI 与传统 BIOS 的主要区别：

| 特性         | BIOS                      | UEFI                                                       |
| ------------ | ------------------------- | ---------------------------------------------------------- |
| **全称**     | Basic Input/Output System | Unified Extensible Firmware Interface                      |
| **架构**     | 16位，基于实模式          | 支持32位或64位，功能更强                                   |
| **启动方式** | MBR 分区，最大支持2TB硬盘 | 支持 GPT 分区，支持超大硬盘（>2TB）                        |
| **界面**     | 文本界面，操作不便        | 图形化界面，支持鼠标操作                                   |
| **安全性**   | 较弱                      | 支持 **安全启动（Secure Boot）**，防止恶意软件在启动时运行 |
| **启动速度** | 较慢                      | 更快，支持并行初始化硬件                                   |
| **可扩展性** | 差                        | 强，支持模块化加载驱动和应用                               |

BIOS/UEFI(新式主板)是电脑开机后第一个运行的程序，作用是“管理硬件、启动系统”。

## 安装系统

### 准备

一个提前制作好的系统启动U盘：

1、去微软官网下载win11的ISO镜像文件（一个几GB的压缩包，包含完整系统安装文件，需要花钱）

2、制作启动盘，用工具（如Rufus、UltralSO）将ISO镜像写入U盘（不是简单的复制），让U盘变成“可引导设备”，这样BIOS才会识别它是“系统安装盘”。

### 插入安装介质，开机进入BIOS/UEFI设置

把制作好的启动U盘插入新电脑的USB接口，按照主板规定的 “键盘快捷键” 进入BIOS界面（联想是在开机过程中长按F12）

### 在BIOS/UEFI中设置“启动顺序”

进入BIOS界面后，找到“启动选项”，里面会显示所有可启动的设备（U盘会显示为USB Device或者具体品牌名。

将U盘设置为“第一启动项”，保存并退出

### 重启电脑

保存BIOS设置后，电脑会重启，此时会读取U盘里的系统安装程序，屏幕会显示windows安装界面：选择语言、系统版本号等

### 将系统安装到电脑自带的硬盘

1、进入“安装类型”界面，选择“自定义：仅安装windows（高级）”

2、此时会显示电脑自带的硬盘，先分区。点击新建，给分区分配空间大小，点击应用。

3、选择创建的C盘分区，点击“下一步”，系统会自动将文件复制到硬盘，期间电脑会自动重启多次

### 完成初始化设置

重启后，电脑会从硬盘（而不是U盘）启动，此时需要完成：

等待系统自动安装驱动和更新，最终进入桌面，至此，系统安装完成。

### 总结

1、BIOS/UEFI是主板自带的，和硬盘、系统无关，只负责“启动引导”

2、新电脑装系统的核心是“借助外部启动设备”：用U盘引导电脑读取安装程序，再将系统“复制”到自带的硬盘分区里；

3、整个流程的本质：把U盘中的“系统安装包”解压到电脑硬盘，并在硬盘中建立“引导程序”，让后续开机时，BIOS能找到硬盘里的系统，并启动。

4、windows、IOS、Linux等系统，流程类似，只是系统镜像和安装界面不同，核心都是“通过BIOS设置启动顺序，从外部设备引导安装。

## windows安装和linux系统安装的区别和相同点

### 版本对比

#### 内核版本

1、linux内核版本（Kernel Version）:

这是最接近“Linux 本身”的版本，由 Linus Torvalds 团队维护。

版本号：6.10，5.15，4.19

2、windows内核版本：Windows NT 内核

#### 发行版本（系统版本）

1、linux发行版本：

Ubuntu、Debian、Fedora、CentOS Stream Arch Linux

2、windows发行版本：win11 

#### 图形界面 GUI

1、Linux图形化界面GUI：

Ubuntu和Fedora 默认自带的GNOME图形化界面

2、windows图形界面GUI：Windows Shell

### Windows vs Linux 的结构对比

| 类比项              | Windows                                       | Linux（以 Ubuntu 为例）            |
| ------------------- | --------------------------------------------- | ---------------------------------- |
| **整体系统**        | Windows 10 / 11                               | Ubuntu 24.04                       |
| **内核（Kernel）**  | Windows NT 内核                               | Linux 内核（如 6.8）               |
| **发行版/版本号**   | Windows 11 23H2                               | Ubuntu 24.04 LTS                   |
| **桌面环境（GUI）** | Windows Shell（资源管理器、任务栏、开始菜单） | GNOME（默认），也可换 KDE、XFCE 等 |
| **是否一体安装？**  | ✅ 是，安装 Windows 光盘就包含一切             | ✅ 是，安装 Ubuntu 镜像也包含一切   |

### 总结

Ubuntu和win11一样，安装之后，都有操作系统，而不是只有命令行。
